(B) (p ∧ q) → p
(C) p → (p ∧ q)
(D) ((p → q) ∧ (q → r)) → (p → r)

B. (A), (C) and (E) Only

== concept
### Tautology check karne ke 2 tareeke

2. **Falsify karne ki koshish** — implication X → Y sirf tab False jab X = T aur Y = F. Agar aisa assignment possible nahi → tautology.
### Yaad rakhne wale tautologies
- Simplification: (p ∧ q) → p
- Addition: p → (p ∨ q)
- Hypothetical syllogism: ((p→q) ∧ (q→r)) → (p→r)

- (C) p = T, q = F: LHS T, RHS F → **not** tautology.
- (D) Hypothetical syllogism → **tautology**.
