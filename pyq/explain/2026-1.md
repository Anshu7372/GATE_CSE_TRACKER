== hint
Statement = "**Agar teacher room me hai → sab students khade + chup.**" Iska **contrapositive** hamesha sach hota hai, par **converse** ("sab khade hain → teacher room me hai") zaroori nahi.
== concept
### Conditional statement: P → Q
"When/If P, then Q" ko logic me **P → Q** likhte hain. Yahan:
- P = teacher room me hai
- Q = sab students standing **and** silent

### Kya-kya pakka sach hota hai?
- **Contrapositive**: ¬Q → ¬P ("agar koi student standing-silent nahi, to teacher room me nahi"). P → Q ke equivalent hai → **hamesha sach**.
- **Weakening Q**: Q = (standing ∧ silent). Agar P → (A ∧ B), to P → A aur P → B dono sach. Isliye "teacher room me → sab silent" aur "teacher room me → sab standing" dono sach.

### Kya pakka nahi?
- **Converse**: Q → P ("sab khade hain to teacher room me hai"). Ye P → Q se follow **nahi** karta. (Students kisi aur wajah se bhi khade ho sakte hain.)
- **Inverse**: ¬P → ¬Q bhi follow nahi karta.
== tips
- Yaad rakho: **P → Q ≡ ¬Q → ¬P** (contrapositive). Converse aur inverse "fallacy" hain.
- "Not necessarily true" puchha ho to converse/inverse wala option dhundo.
- Q me "and" ho to uske tukde (sirf A, sirf B) bhi P se follow karte hain.
== sol
P = teacher in room, Q = all students stand silently (standing ∧ silent). Given: P → Q.
- (A) "Koi student standing-silent nahi → teacher room me nahi" = ¬Q → ¬P = contrapositive ✓ (true).
- (B) P → silent ✓ (Q ka hissa).
- (D) P → standing ✓ (Q ka hissa).
- (C) "Sab students standing → teacher room me" = converse type ✗ — **zaroori nahi**.

**Answer: (C)**
== refs
- Kenneth Rosen — Discrete Mathematics, Sec 1.1 (Conditional statements: converse, contrapositive, inverse).

Jab experiment kai steps me ho aur har step ka result agle step ki probabilities badal de, to:

- B nikla (1/2) → ab 1R, 2B (total 3)

- 2R1B se B nikle (1/3) → 2R2B ✓ ; R nikle (2/3) → 3R1B

== hint
Top-left **3×3** block ke 9 entries free choose karo (2⁹ = 512 ways). Last column, last row aur corner apne aap fix ho jaate hain (parity even banane ke liye), aur ye hamesha consistent hote hain → **512**.
== concept
### Parity kya hai?
Kisi row/column me 1s ki ginti **even** hai to parity even. 0/1 ko mod 2 arithmetic se socho: row ka XOR = 0 ⇔ even 1s.

### "Free choice + forced rest" counting
4×4 matrix me 16 entries. Condition: har row even, har column even.
- Top-left 3×3 ke 9 entries koi bhi 0/1 rakho.
- Har row i (1..3): 4th entry = us row ke pehle 3 ka XOR (taaki row even ho) → forced.
- Har column j (1..3): 4th row ki entry = us column ke upar wale 3 ka XOR → forced.
- Corner (4,4): row 4 even banane ke liye ek value, column 4 even banane ke liye ek value. **Dono same aate hain**, kyunki dono = poore 3×3 block ka XOR (sab 9 entries ka parity).
To har 3×3 choice se exactly ek valid matrix → 2⁹ = 512.

### General formula
m×n 0/1 matrix, sab rows aur columns even → **2^((m−1)(n−1))**. (4×4 → 2⁹.)
== tips
- Formula 2^((m−1)(n−1)) yaad rakho; chhote case check: 2×2 → 2¹ = 2 (all-zero aur all-one) ✓.
- Options me 2ⁿ ± 1 (1023, 1025, 255) trap hote hain; parity questions me answer power of 2 hota hai.
== sol
1. 3×3 top-left block free: 2⁹ choices.
2. Rows 1–3 ka last entry forced, columns 1–3 ka last entry forced.
3. Corner: row-4 rule aur column-4 rule dono 3×3 block ke total parity ke barabar → consistent, ek hi value.
4. Total = 2⁹ = **512**.

**Answer: (A) 512**
== refs
- Kenneth Rosen — Discrete Mathematics, Ch. 6 (counting: product rule).
- Linear algebra view: GF(2) me ye constraints ka solution space dimension (m−1)(n−1) (Gilbert Strang — Linear Algebra, null space idea).

A·v = λ·v (v ≠ 0). λ = eigenvalue, v = eigenvector.

Identity Iₙ: det(I − λI) = (1 − λ)ⁿ → λ = 1, multiplicity n. Zero matrix: λ = 0 multiplicity n.

== hint
Immediate = value instruction me hi (**constant**). Indirect = address ka address (**pointer**). Base + index = base address + variable index (**array element**). Base + fixed offset = struct/record ka **field**.
== concept
### Addressing modes (operand kahan hai?)
- **Immediate**: operand ki value instruction ke andar hi. `ADD R1, #5` → constant 5.
- **Direct**: instruction me memory address; operand = M[address].
- **Indirect**: instruction me ek address, us location pe **asli operand ka address** pada hai. Operand = M[M[addr]] → ye pointer jaisa hai (`*p`).
- **Base with index (indexed)**: EA = base register + index register. Base = array ka start, index = i × size badalta rehta hai → `a[i]`.
- **Base with offset/displacement**: EA = base register + **constant** offset. Record/struct ka start base me, field ka fixed offset → `r.field` (jaise `s.marks` hamesha start se 8 bytes aage).

### High-level mapping
- Constant ↔ immediate
- Pointer dereference ↔ indirect
- Array element (variable index) ↔ base + index
- Record field (fixed offset) ↔ base + displacement
